# ADR-0004: Broad legacy masks confound set-continuity measurement

## Status

Accepted from the 2026-08-31 G07a/G07b preflight.

## Evidence

The valid zero-mask reconstruction control had mean absolute change of 0.0084. The four sequential role-swap outputs retained the requested left/right identities in agent visual triage, but broad rectangular target regions allowed substantial regeneration of kitchen furniture and architectural details inside those regions. Non-target change alone therefore cannot measure set continuity.

## Decision

Do not use broad 2D rectangular masks as evidence that a renderer preserves a recurring set. Keep this sequential-inpaint adapter as a non-scoring repair research arm. Treat its apparent role-binding advantage as provisional until controls distinguish actor-only edits from collateral set edits.

## Consequences

The next local experiment must improve control granularity or use composited actor plates/mattes while preserving frozen semantics. Canonical 3D/set/camera assets remain the required route to grounded benchmark claims. No current output is production accepted.
