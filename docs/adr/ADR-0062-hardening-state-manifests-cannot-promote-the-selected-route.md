# ADR-0062: hardening-state manifests cannot promote the selected route

- Status: accepted
- Date: 2026-09-01

## Context

Selection, local mechanics, runtime reproducibility, chapter readiness, review status, licensing, and authority were spread across many records. A consolidated handoff is useful, but it could overstate OpenAI's engineering selection as accepted art, commercial clearance, or production authority.

## Decision

Compile a hash-pinned state manifest that preserves each evidence dimension and its limitation separately. Keep the OpenAI choice explicitly limited to engineering hardening. Preserve null/zero review, accepted-art, approved-input, authority, reservation, outcome, and production-cost fields. Do not create a composite score or automatic reselection.

## Consequences

- The manifest records 16 required G07 candidates, $1.057377 aggregate spend, and the selected arm's four candidates / $0.198621 / 128.347 seconds.
- Human review remains 0/20 decisions, null minutes, zero accepted, and no arm results or ranking.
- Local evidence records 16px/5px panel-specific profiles, 26 exact rebuilt artifacts, and synthetic-only boundary measurement.
- Chapter state remains 50 plans, four explicit candidates, two profiles, one policy, nine P036 blockers, and zero real outcomes/$0 production.
- Fifteen/fifteen acceptance, authority, review, universal-width, denominator, budget, medium, and limitation mutations fail.
