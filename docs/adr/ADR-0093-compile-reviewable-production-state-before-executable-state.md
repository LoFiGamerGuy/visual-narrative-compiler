# ADR-0093: Compile reviewable production state before executable state

- Status: accepted
- Date: 2026-09-01

## Context

The strongest 14 CH05 candidates now form three measured sequences, but none has owner candidate acceptance, commercial clearance, final copy, validated final lettering, generation reproducibility, or sequence acceptance. A deterministic compiler binds each exact ComicPanelPlan snapshot, prompt/reference/source hash, engineering review, cadence role, layout, recommended lettering mode, and missing gate. A separate local HTML index makes all 29 new candidates, 14 selections, 12 review artifacts, and three non-canon concepts browsable.

The compiled 14-row manifest is byte-identical across consecutive runs and rejects 15/15 promotion mutations. The review index is byte-identical across consecutive builds, validates every HTML link/artifact hash, and rejects 12/12 coverage/promotion mutations.

## Decision

Make `REVIEW_READY_NONEXECUTABLE_OWNER_DECISIONS_PENDING` a first-class chapter state. Do not infer executable production state from engineering selection or a coherent visual assembly.

Use the local owner review index as the primary handoff surface. Keep its HTML, thumbnails, and every generated pixel ignored; track only the builder, exact hashes, coverage evidence, and decisions. Preserve non-canon concepts as a separate section and never allow them into CH05 rows.

## Consequences

- Each selected row exposes the exact reasons it cannot execute or promote.
- Review can proceed from one linked index without publishing or uploading art.
- Final copy, lettering semantics, exact candidate acceptance, finish-density preference, commercial eligibility, and reviewer minutes remain owner decisions.
- No provider call, upload, spend, plan revision, or production acceptance follows.
