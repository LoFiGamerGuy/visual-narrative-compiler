# ADR-0096: Expand chapter coverage through clue chains, not more hero panels

- Status: accepted
- Date: 2026-09-01

## Context

The selected 14 cover all four practical-action ComicPanelPlans but only 2/10 directional, 6/26 observation, and 2/10 sensory plans. The remaining 36 are exactly partitioned into three 12-panel tranches. Tier A contains two coherent six-panel chains: trail water/twine/redirection and mill reveal/smoke/red-cloth/loading-door approach. Tier B completes drum/bell/interior/false-track/tin-map mechanics. Tier C fills departure and final-return connective beats plus the one explicit says-beat whose final copy is absent.

The current run already has 29 candidates, near the requested upper target. More hero images would add less chapter-production information than the missing clue and connective chains.

## Decision

After owner review of the current 29, use Tier A as the next bounded generation tranche. Do not generate it automatically during this run. Preserve its six-panel sequence grouping and exact plan order; do not replace it with disconnected beauty shots.

Keep the one explicit says-beat P016 in Tier C until final copy and lettering semantics exist. Priority orders production evidence, not canon importance.

## Consequences

- Selected plus Tier A/B/C is an exact disjoint 50-plan partition.
- The next production expansion targets trail/mill narrative continuity rather than already-covered practical action.
- All 50 ComicPanelPlans remain unchanged; no new prompt, copy, execution, provider activity, or acceptance is created.
- Owner decisions on exact candidates, density rhythm, and lettering should inform any future Tier A style assignments.
