# ADR-0105: Preflight hypotheses do not authorize prompt compilation

- Status: accepted
- Date: 2026-09-01

## Context

ADR-0104 recommends P010–P013 after owner review. The four plans need provisional style, width, reference, continuity, lettering, and repair-slot assumptions to expose conflicts before generation. Those assumptions must not silently become prompts or upload authority.

## Decision

Compile a fail-closed four-row preflight contract with null prompts, null outputs, zero uploads, and four nonexecutable style/scale/reference hypotheses. Require current candidate/style review, microsequence cadence approval, final-copy-or-silence binding, and exact reference selection before prompt compilation.

Keep two repair slots unallocated. A slot may change one exact constraint cluster only after a retained failure identifies its trigger; broad rerolls are forbidden.

## Consequences

- P010–P013 map to cel-painted 820px character clue, clear-line 640px causal clue, text-only limited-ink 560px insert, and clear-line 1,040px directional re-entry hypotheses.
- Three reference IDs are hypotheses only; actual uploads remain zero.
- All four rows retain exact ComicPanelPlan and continuity/scale bindings; AnimationShotPlan and E-Conte remain null.
- Twenty-five/twenty-five mutations fail; decisions/copy/prompts/executable rows/calls/uploads/spend remain zero.
