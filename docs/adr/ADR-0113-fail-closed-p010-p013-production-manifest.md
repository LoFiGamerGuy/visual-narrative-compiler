# ADR-0113: Fail-closed P010–P013 production manifest

Date: 2026-09-01

Status: Accepted as a dry-run contract

## Context

P010–P013 is the highest-information next microsequence because it traverses Sigrid-only listening, Soren-only hand/object interaction, a no-person causal insert, and dual-adult directional re-entry. The prior preflight defines styles, widths, reference hypotheses, and two bounded repair slots but does not expose a chapter-production-shaped RenderRecord contract or planned review outputs.

## Decision

Compile a four-row production-manifest dry run that preserves every prompt, output, service-metadata, review, acceptance, and execution field as null/false. Carry the existing two unallocated repair slots, require all review/route/cadence/copy/reference/commercial gates before prompt compilation, and predeclare five deterministic review artifacts.

## Evidence

- Four exact ComicPanelPlan rows: P010, P011, P012, and P013.
- Three reference hypotheses, zero uploads.
- Five planned review artifacts: candidate contact sheet, 390px phone sheet, continuity sequence, safe-zone sheet, and style-density-cadence comparison.
- All RenderRecord output/service/review fields remain null; all rows remain nonexecutable and unaccepted.
- 20/20 malformed state/denominator/planning mutations are rejected.

## Consequences

- The manifest is reproducible production metadata, not generation authority.
- Prompt compilation remains blocked until the explicit gates are resolved.
- Only one failure class may be changed in each bounded repair slot; passing rows are preserved.
- ComicPanelPlan remains the sole production structure; AnimationShotPlan and E-Conte remain null.
