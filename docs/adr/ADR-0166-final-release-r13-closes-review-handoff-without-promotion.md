# ADR-0166: Final release r13 closes review handoff without promotion

Date: 2026-09-01

Status: Accepted

## Context

Completion readiness proves deliverable coverage, but a final integrated gate must replay the complete reproducer together with post-reproducer source, completion, cost, current hub/links, frozen/source scope, and remote parity.

## Decision

Use final review reproducer r3 as a ten-domain base and add eight current domains. Run nine local/no-network commands, normalize only two live decimal tracked-path diagnostics, and bind all script/stdout hashes. Advance cost ledger r30 append-only.

## Evidence

- Nine/nine commands pass in 194.497 seconds, representing 18 effective domains.
- Independent replay passes and rejects 33/33 state, result, normalization, activity, count, and planning mutations.
- State binds 29 candidates, 50 plans, 12 batches, 134 links, 67 priority links, 112 worksheet checks, release 84, source 971, cost 91, frozen 16 + baseline 4.
- Provider calls/uploads/owner inputs/ingestion/dispositions/acceptance/clearance/execution/spend remain zero; human minutes remain null.
- Ledger r30 records 91 zero-external-cost milestones.

## Consequences

The final review handoff has one integrated no-network release gate. Passing closes engineering delivery only; all owner review, visual disposition, acceptance, rights, exact-base, and production transitions remain explicit future work.
