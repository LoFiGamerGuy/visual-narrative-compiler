# ADR-0179: Require a post-chapter integrated release before owner handoff

- Status: Accepted
- Date: 2026-09-02

## Context

CH05 r6 now spans generated evidence, assembly, lettering, cross-chapter continuity, a future authoring contract, and semantic validation. Each component can pass alone while a source hash, frozen baseline, planning boundary, or Git lineage has drifted elsewhere.

## Decision

Run one no-network integrated release matrix before declaring the current handoff coherent. The matrix must cover the r6 release, chapter inventory, cross-chapter visual regression, authoring contract/template, semantic graph validator, r6 production and assembly records, frozen gauntlet/baseline, tracked-source scope, and current main/origin parity.

## Result

Ten/ten commands and 93 effective checks pass in 4.481 seconds. The release record binds each script, argument vector, return code, stdout hash, elapsed time, and no-network declaration. Its own validator rejects 12/12 adversarial mutations.

## Consequences

- Component evidence and repository state are checked together before the review pointer is refreshed.
- Passing proves integrity only. It grants no story, prompt, provider, upload, generation, acceptance, commercial rights, exact-base, or production authority.
