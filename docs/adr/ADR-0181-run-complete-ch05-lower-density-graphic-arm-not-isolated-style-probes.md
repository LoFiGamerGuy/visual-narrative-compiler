# ADR-0181: Run a complete CH05 lower-density graphic arm, not isolated style probes

- Status: Accepted for execution within the existing built-in ImageGen/reference boundary
- Date: 2026-09-02

## Context

The owner requested that style improvement happen in parallel with complete-chapter production rather than through a small number of disconnected beauty shots. CH05 r6 provides a fixed 50-panel story baseline, but its clear-line watercolor/cel hybrid cannot answer whether a cleaner, lower-density graphic treatment improves phone readability, action, and cadence across an entire chapter.

## Decision

1. Preserve CH05 r6 unchanged as the current review baseline.
2. Generate a separate complete 50-panel alternate arm using the same 11 sequence ranges and exact approved ComicPanelPlans.
3. Use a clean lower-density graphic adventure treatment: decisive contours, simplified shadow/color shapes, limited cold-wet palette, selective face modeling, and minimal decorative texture.
4. Preserve current fictional-adult hair/wardrobe identity and exact per-panel story/cast/causal/lettering requirements.
5. Use only the existing OpenAI built-in ImageGen product and the three authorized hash-pinned fictional-adult references. No BFL, direct paid API, new provider, new upload class, real person, child material, or G07 budget.
6. Instrument every output and compare the two complete chapters on role/count/order, causal action, identity/wardrobe, phone readability, lettering clearance, rhythm, cost/latency disclosure, and reproducibility limitations—not visual appeal alone.

## Consequences

- Eleven exact prompts cover P001-P050 once and plan 23 authorized reference uses.
- R6 remains immutable; the alternate arm starts unaccepted and commercially uncleared.
- The arm introduces no armor, weapons, monsters, magic, or new canon because CH05's approved plans do not contain them.
