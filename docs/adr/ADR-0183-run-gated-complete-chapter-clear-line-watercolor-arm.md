# ADR-0183: Run a gated complete-chapter clear-line watercolor arm

## Status

Accepted for the already-authorized OpenAI built-in ImageGen product and exact three hash-pinned fictional-adult references.

## Context

The alternate-graphic arm provided full-chapter evidence but did not materially separate visual density and omitted several cross-panel invariants. Isolated style probes would not measure chapter rhythm or recurrence of those failures. The user requested complete chapters, varied style, phone readability, stable hair/wardrobe, and parallel improvement.

## Decision

Run one further 11-request, 50-ComicPanelPlan chapter arm in mature clear-line adventure art with controlled transparent watercolor, broader quiet shapes, and explicit avoidance of photorealism, crosshatching, and dense microtexture. Every request remains within the existing built-in ImageGen authorization and exact reference allowlist. The prompt manifest must pass all eight cross-panel semantic gates and 15 exact phrase bindings before execution.

## Consequences

This is a full-chapter hardening/style-separation experiment, not a preselected replacement for r6. Generated pixels remain ignored and unaccepted. Model, endpoint, provider request ID, usage, cost, and seed remain unavailable unless the product exposes them. Direct paid APIs, BFL, new upload classes, cloud GPUs, and child/real-person material remain prohibited.
