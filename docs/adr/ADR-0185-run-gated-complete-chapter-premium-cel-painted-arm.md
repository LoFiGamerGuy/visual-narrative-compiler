# ADR-0185: Run a gated complete-chapter premium cel-painted arm

## Status

Accepted for the already-authorized OpenAI built-in ImageGen product and exact three hash-pinned fictional-adult references.

## Context

The clear-line-watercolor arm improved several causal and character-readability outcomes but remained denser than r6 and retained three semantic failures. A complete premium cel-painted route is the next requested style family and measures whether deliberate two-tier shadow shapes, clean contour hierarchy, and selective background paint can improve phone readability and motion without losing chapter state.

## Decision

Run 11 sequence requests covering the same 50 approved CH05 ComicPanelPlans under the existing eight cross-panel gates and 15 exact prompt bindings. Use bold clean contours, shaped two-tier cel shadows, restrained highlights, selective atmospheric backgrounds, reduced microtexture, and broad quiet shapes for dialogue, deduction, travel, and inserts. Preserve exact adult hair, wardrobe, cast, causal action, lettering-safe fields, and text-free output constraints.

## Consequences

The arm is comparison evidence, not a preselected replacement. Each output must receive an exact execution record, deterministic crops, clean/lettered/phone/continuity packets, and non-gating semantic triage before selection. Generated pixels remain ignored and unaccepted. No paid API, BFL, new provider, new upload class, license conclusion, or commercial-use decision is authorized.
