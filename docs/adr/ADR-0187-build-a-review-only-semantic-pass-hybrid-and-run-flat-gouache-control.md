# ADR-0187: Build a review-only semantic-pass hybrid and run a flat-gouache control

## Status

Accepted as an engineering and review recommendation. It does not grant visual acceptance, rights, or production-base status.

## Context

No single complete route dominates every requirement. R6 has the lowest defect burden but cross-panel failures at P001 and P041. Clear-line and premium-cel each solve useful panels while introducing other regressions. The targeted repair tranche supplies a passing cold-house/downhill P001 and a passing simultaneous-three-mark P039; P032 remains the only unresolved warning.

The alternate, clear-line, and premium style prompts all produced medium-to-high texture despite different style labels. A truly flat graphic-gouache complete arm is therefore a higher-information density test than another isolated style probe.

## Decision

Create a review-only 50-panel hybrid from exact measured PASS candidates: 28 r6, 9 clear-line, 11 premium-cel, and 2 targeted repairs. Keep r6 P032 as WARN and select no failing candidate. Assemble and letter the complete chapter, but record its 33 adjacent route transitions as a finish-continuity limitation.

Then run the preflighted flat graphic-gouache 11-sequence / 50-plan control. Its prompts constrain each panel to broad poster-like 4–6 value/color masses, one localized active-clue texture at most, simplified silhouette backgrounds, and explicit bans on pore, weave, pebble, crosshatch, photoreal, depth-of-field, and grayscale-wash treatments.

## Consequences

The hybrid measures 49 PASS / 1 WARN / 0 FAIL with P032 the sole warning, but it is not a uniform-finish production recommendation. The flat-gouache arm must pass the same eight cross-panel gates and 15 exact prompt bindings before generation and will be judged by semantic behavior, role continuity, phone readability, lettering clearance, measured density, latency, and reproducibility limitations—not visual appeal alone.
