# ADR-0207: Use the four-chapter progression hub and promote CH10 next

## Status

Accepted for review navigation and production sequencing.

## Context

Four complete visual chapters now exist, but separate chapter folders make progression difficult to judge in one pass. The owner requested breadth, drastic change over time, and less repeated chapter rendering.

## Decision

1. Bind CH06–CH09 into one deterministic progression manifest and three cross-chapter review images.
2. Show fixed ordinal samples as navigation, never as an automated quality ranking.
3. Preserve all chapter-specific failures and warnings rather than hiding them in aggregate counts.
4. Keep one default route per chapter and advance chronologically to CH10 before any wholesale style arm.
5. Keep generated pixels ignored and keep acceptance, rights, commercial clearance, exact-base selection, and reproducibility false or pending.

## Evidence

Four source packet hashes bind 160 candidates and 32 sequence sources. Combined non-gating triage is 153 PASS / 4 WARN / 3 FAIL. The builder emits three deterministic review artifacts; the validator passes and rejects 10/10 adversarial mutations.

## Consequences

The owner can now compare four chapters and visible state changes in one surface. The hub does not change any candidate disposition. The next production gate is CH10, whose authored state introduces the Brackenwake faction, rigid brace, forged Warden's Reach, Sigrid-owned bow/seax, quarry guards, and Tamsin transport.
