# ADR-0216: Use explicit irreversible-state blocks and group critical panels

## Status

Accepted as a prompt-engineering recommendation. Diagnostic pixels remain unaccepted, commercially uncleared, non-reproducible, and outside the selected chapter assemblies.

## Context

CH12 and CH13 repeatedly restored Soren's oatmeal left-shoulder panel after its authored irreversible sacrifice. The authorized CH05 identity references depict the intact pre-sacrifice coat, so using them in a repair could actively conflict with the desired state.

## Decision

1. Test five exact visible-shoulder targets in one text-only strip with zero reference uploads.
2. Require a named irreversible-state block in every later sequence prompt after a material costume or injury threshold.
3. Group adjacent state-critical targets within one request when story cadence allows.
4. Treat within-call success as prompt evidence only; do not infer independent-call persistence.
5. Keep all five crops diagnostic until explicit owner disposition and a hash-preserving assembly revision.

## Evidence

One 108.2-second built-in request produced five deterministic crops. Agent triage is 5 PASS / 0 WARN / 0 FAIL for visible shoulder absence; the fifth panel also removes Crownroot's human-face relief. Reference uploads, paid API calls, cloud GPU operations, and direct paid spend are zero. The validator rejects 10/10 mutations.

## Consequences

The highest-value continuity defect has a viable prompt-level mitigation without new upload authority. Identity reproducibility is weaker in a text-only arm, and cross-call persistence remains unproven. No baseline chapter candidate is silently replaced.
