# Binding failure-correction contract

| Failure | Observable symptom | Root-cause hypothesis | Preventive production rule | Pilot acceptance test | Chapter-scale test | Fail-closed response |
|---|---|---|---|---|---|---|
| Busyness / eye strain | Competing focal regions, texture in quiet beats, effects blanket figures | Detail labels were trusted instead of rendered evidence | At least 11/16 pilot panels are genuinely low detail; one focal point; quiet beat at least every four panels; no adjacent maximum-density panels | 390px focal identification, grayscale separation, edge/entropy calibration, manual PASS for every planned-low panel | ≥65% low, 23–27% moderate, 8–12% high; ≤25% planned-low panels may exceed accepted calibration | Block batch; simplify prompt/grouping/background and regenerate only failing panels |
| Generic style convergence | Soft painterly fantasy, game-splash poses, repeated value wash | Broad style prose and multi-moment sheets overwhelm line/shape controls | Crisp tapered contour, limited internal lines, two-step cel shade, matte shapes, one accent family; critical panels generated individually | Same adult lead passes close-up, silhouette, reaction, action, skill, boss, quiet-space evidence at phone size | Per-chapter recognition review and cross-experiment differentiation checklist | Reject candidate/route; one bounded refinement, then fallback only if all candidates fail |
| Named-source translation failure | Research names appear but pacing/action/scale do not | Inspirations were treated as adjectives | Translate only documented high-level principles into camera, motion, pacing, and progression rules | Immediate dungeon objective, vertical scale, expressive close-up, six causal action beats, visible change | Each chapter opens with condition/objective and closes on consequential turn; action ratio 35–45% | Block pilot/chapter until visible proof exists |
| Poor lettering | Giant rounded cards, speaker labels, weak tails, unreadable phone type | Fixed rectangles and art-first placement | Organic SVG balloons, measured wrapping, semantic tail anchors, under-16-word ordinary copy, distinct system UI | Manual 390px legibility; no protected-feature collision; dialogue visibly differs from UI | Collision/coverage/read-order validators plus manual review | Reposition or split copy locally; never rerender art for local lettering defect |
| Weak action / spectacle | Static poses, unclear target/contact, no consequence | Scene engine favored discussion and single splash tableaux | Action plan must establish geography → threat → initiate → counter → impact → consequence → adaptation → payoff | Panels P05–P15 form a readable causal chain; spectacle follows setup | 35–45% action, ≥6 fights, ≥3 bosses, chase/hazard, combo, defeat, breakthrough | Block selection; targeted action-panel repair only |
| Complexion homogenization | Neutral-light lead reads outside fair/light contract or lighting erases base value | Vague prompts and color grading | Hash-pinned fresh character anchor; explicit neutral RGB/value logic; warm/cool light notes in every character prompt | Elian remains fair/light in neutral P03 and dramatic P09/P14/P15; supporting Mira distinct | Neutral, warm, cool, dungeon, and magic-light samples reviewed | Reject/repair any identity-critical panel; never reinterpret lighting as complexion |
| Absent LitRPG content | No levels, XP math, class, skill costs, loot provenance, or advancement | Abstract progression substituted for state transactions | Every system notice maps to the authoritative `SystemState`; display only decision-relevant fields | Pilot visibly shows identity/level, XP, quest, boss level, skill cost/cooldown, inventory consumption, breakthrough, loot, class unlock | 2–4 meaningful moments/chapter and all minimum progression-event counts | Arithmetic/provenance error is FAIL; correct ledger or panel before release |

No aggregate beauty score can override any hard-gate failure.
