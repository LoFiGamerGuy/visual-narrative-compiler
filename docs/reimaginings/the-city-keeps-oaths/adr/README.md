- [ADR-001 — premise, schema, and production route](ADR-001-premise-schema-and-route.md): records the preregistered premise rubric, selected original story, `ComicPanelPlan`-only schema, and isolation boundary.
- [ADR-002 — style selection](ADR-002-style-selection.md): records the fixed style rubric, three-candidate comparison, Candidate A selection, and originality exclusions.
