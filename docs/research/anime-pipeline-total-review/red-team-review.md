# Red-team review and lead disposition

Independent memo: `evidence/red-team-independent.md`. The red team was not told to prefer C; they were given the draft to attack. This file is the lead’s disposition. Minority conclusions are preserved.

## Objection 1 — Cherry-pick: A’s plate diagnosis + B’s Ember loyalty

**Red team:** Weighted midpoints average 2+ disagreements. Visual A ranks Borrowed Down first and Ember volume last among the three IPs. Visual B ranks Ember volume first (3.11). C is assembled from the pairing that most favors rebuilding Ember.

**Disposition: accepted as a warning, not as a veto.** The midpoint table is diagnostic, not a vote. C is not “Ember scored highest.” C is: (1) story/ledger evidence that Ember is the only numeric LitRPG that matches the owner’s genre ask; (2) plate evidence that overlays cannot restage fights; (3) two prior IPs already tested greenfield. Visual A’s ranking of Borrowed Down is preserved: that title has the strongest *drawings*, the wrong *format* for the named bar, and broken lettering. We do **not** treat 2.62 as Ember’s score.

## Objection 2 — Strategy A still wins

**Red team:** Owner approved Candidate B and asked for lettering/system polish; hybrid moved the only measured page metrics; Visual B’s 3.11 is a working serial (rubric 3).

**Disposition: A is the last completed programme, not the next one.** Lettering gains are real and kept. Rubric 3 is “not the named bar.” Owner’s 2026-09-06 sentence lists improvement, different approach, *or* restart after that polish. Targeted redraws remain the lowest-cost plates inside the 14-panel control. Scaling A (another overlay pass, another ten chapters) is rejected.

## Objection 3 — The 14-panel test is B-sized; calling it C is branding

**Red team:** Changing every stage at once is unfalsifiable. Ember already generates one panel per plan. Lettering already was a successful modular swap.

**Disposition: accepted. Operational next step is B-inside-C.** C is the architecture *hypothesis* (storyboard authority before finish). The 14-panel bakeoff changes **one** variable first: locked layouts vs current hybrid, same generator. If that wins, C stays lean (B was enough). If layouts are ignored, full layered finish is required or we stop. We will not staff a 6–7 person factory on this pilot.

## Objection 4 — Immediate D

**Red team:** Owner listed restart; page-level hook/emotion are 2–3; Visual A ranks Ember last among IPs.

**Disposition: D stays fallback, not tonight.** City and Borrowed Down were already new IPs. Immediate D without a storyboard test repeats finished-image-first under new nouns. If H1+H2 pass and the owner still rejects Ember, D fires.

## Objection 5 — Ember premise is not proven

**Red team:** 99/100 was pre-page; identity drifts volume vs premium; the ledger also flattened propulsion.

**Disposition: accepted.** Ember is a *payload to test* (H3), not a proven property. The ledger is kept as arithmetic, not as a 24-panel metronome.

## Objection 6 — C is infeasible; human minutes are null

**Red team:** C is a studio script without staff, cap, or renderer.

**Disposition: accepted as kill criterion.** If the owner will not record review minutes, stop. Do not simulate a studio with another agent. The pilot’s human load is storyboard + correction of faces/hands/contact, not a weekly factory.

## Objection 7 — Comparables overclaim

**Red team:** ToG/SL panel craft is `not_assessed`; interviews are not a measured bar.

**Disposition: accepted.** Named-bar comparison is high-level transfer only. We do not score ToG/SL panels. Popularity is context.

## Objection 8 — Unevidenced leaps and empty B justifications

**Red team:** “In the plates ⇒ replace the spine” is a leap. Reconciliation dropped B’s reasons. Visual B JSON justifications were empty.

**Disposition: accepted on process.** Visual B’s `notes.md` is the written analysis; the JSON justifications were empty at first write and are being backfilled without changing scores. “Error is in the pixels” supports A (replace those pixels), B (change the producing stage), or C (change the spine). The 14-panel is how we tell those apart. We will not skip it.

## Objection 9 — Borrowed Down + Ember SVG lettering

**Red team:** Agreed diagnosis could be “keep BD drawings, port Ember overlays.”

**Disposition: preserved alternative, not the owner bar.** The owner asked for compelling action manhwa/webtoon in the ToG/SL *feeling*, not a print lithograph with better captions. BD+SVG is a valid modular experiment if the owner later chooses that taste. It is not the default payload.
