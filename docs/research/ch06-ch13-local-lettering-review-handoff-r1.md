## Important geometry correction

The plan field `rect_norm` stores `[left, top, right, bottom]` corners. Several historical overlay builders interpreted the final pair as width/height, which can clip right-anchored treatments. This packet uses the corrected corner semantics. Historical overlay artifacts remain immutable diagnostics but are not authoritative for final placement.

## Limitations

- Copy is a review draft, not final canon dialogue.
- Safe-zone contracts protect declared faces, adult silhouettes, hands, tools, story objects, Ledger surfaces, and causal geometry; no learned pixel segmentation has independently verified every placement.
- Speaker attribution is present in metadata; balloon-tail geometry remains a later typography task.
- All derivative pixels remain ignored, unaccepted, commercially uncleared, and outside exact-production-base status.

## Recommendation

Use the ten-beat density as the default dialogue/caption ceiling for this action-forward arc. Add copy only where a relationship rule, clue, system consequence, or transition cannot be read reliably from action. Keep SFX tied to physical causality and SYSTEM copy attached to local physical substrates.
