TEN BLACK PETAL COVER EXAMPLES

Open index.html to browse the covers. Open overview.html to compare all ten at once. These are illustrative examples with invented sample titles, not covers for identified books.

Each numbered example has two PNGs:
art-NN.png is the original generated illustration without lettering.
cover-NN.png is the supplied cover mockup with sample title and AUTHOR NAME.

You can change the author name and each title in index.html, change title lettering from dark to light, or hide lettering to judge the illustration alone. Save edited page downloads an HTML copy of your edits; keep that copy in this same folder beside app.js, style.css and the images. Cover PNG downloads remain the supplied examples. To share edits as a static document, print the edited page to PDF using your browser.

The ZIP includes the Black Petal source reference, exact generation prompts, image hashes, and the original cover starter kit instructions under source/. Each illustration was generated separately with the same Black Petal style reference. No book title or author text is embedded in the generated source art.

These are front-cover composition examples. A real book's title, author, trim size, spine and back-cover layout can be specified when adapting a chosen example. The current mockups are not printer-specific production files.
