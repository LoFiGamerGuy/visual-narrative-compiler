# Texture refinement

The owner explicitly endorsed the texture change in Nightglass refinement on 2026-09-08 and requested persistent reuse. For this user's narrative-art pipeline, retain this as the preferred finishing method unless superseded. Apply judgment: an already calm image does not need another generation. For other work, follow the current user's desired texture and drawing treatment.

## Proven mechanism

First establish a compelling composition. When surface density competes with it, use a **separate edit of that source alone**, asking for broad intentional light/shadow shapes inside existing contours. Preserve faces, silhouette, material differences, functional contacts, spatial relationships, color and depth. Quiet all-over microfacets, scratches, grain, tiny strands, crack networks and sparkle; keep expressive face detail and meaningful seams. Do not blur, downsample, flatten into vectors or turn materials to plastic. Preserve intentional brushwork or texture belonging to the source's style.

New-generation wording alone was less reliable than this separate source-only pass. Do not combine the pass with new characters, poses, cameras, equipment designs or anatomy/handling repairs. A source-preserving edit can preserve source defects; inspect and handle structural correction separately.

Read [the master prompt](references/master-prompt.txt) before an edit. Customize its protected features and surface priorities from the **actual viewed source**, not generic adjectives. That template is a new adaptation; [tested evidence](references/evidence.md) records what actually ran. Do not import Nightglass characters, palette or demographics into someone else's images.

## Execution and acceptance

Use the available authorized image-editing tool and its instructions. In this project use built-in image generation only; no paid API calls or purchases. Skill selection grants no extra generation budget. If not specified, start with one pass, then at most one targeted retry for an observed failure before reassessing; never fill a budget with beauty variants. No generation is needed for documentation requests.

Inspect the source before editing. Preserve the source and every attempt separately. Record the exact submitted prompt, actual reference paths/hashes, returned native image, tool and known metadata; unknown model snapshot, seed and billing remain unknown. Never invent settings or present the prompt as a deterministic recipe.

Compare before/after at matched phone/thumbnail scale and at native detail. Texture relief must survive checks for identity/expression, anatomy, handling, creature construction, action, composition, material and depth. Reject or mark partial a pass that improves surfaces while damaging these. Owner preference, visual observations and file-integrity checks remain separate. Save process approval without filling individual artwork ratings or selecting canon.

For covers, prefer the art layer. Preserve framing and existing title space; preserve exact typography in the original editable layout outside generation. Do not promise letter-perfect text or change layout under a texture-only brief.
