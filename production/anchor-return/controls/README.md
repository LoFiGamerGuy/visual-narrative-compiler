# Original staging controls

These 24 editable SVGs and matching 1200×800 PNGs are composition diagrams for three eight-beat encounters. They are not final artwork, drawing-style references, or selected canon. No existing artwork, comic excerpt, screenshot or other external image is embedded.

Use each PNG only for its own current beat: relative staging, anatomical hand ownership, weapon/contact relationships, support, motion and present damage state. Use the original drawing anchor and new identity sheet for actual character/creature appearance. Do not copy diagram labels, mannequin faces, simplified polygons, colors, support marks or annotation arrows into final art. The cyan NG tether and ST pressure disk represent story objects; orange arrows describe movement/contact.

Amber arm centerlines identify anatomical right; blue identify anatomical left. Hand labels sit alongside each chain. Green marks show intended support. Quiet/small openers, enlarged cropped contacts, low supported lunges, skewed overhead diagrams and aftermath poses deliberately vary composition. These are schematic projections, not solved 3D cameras or guarantees of correct generated anatomy.

Current-state and contact contracts are copied exactly from the bound plan in each JSON file and `manifest.json`. SVGs retain editable primitives. `research/anchor-return/control-review/` contains source builders, local Chromium rendering code, actual visual review records and file checks. Original generation image inputs remain separate from this diagram system.
