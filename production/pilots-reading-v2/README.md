# Pilot reading edition v2

Open `docs/pilots-reading-v2/index.html` in a browser, including a Windows browser through the offline package. `#NG`, `#BP`, `#ST`, `#RC` and `#FL` select the five complete pilots. This needs no server, fetch request, CDN, build step or network font.

`edition.json` is the editable story/lettering source, generated by `build.py` from the preserved v1 plan plus explicit v2 decisions in that script. Edit persistent decisions in `build.py`, run `python production/pilots-reading-v2/build.py`, then inspect the actual reader. `copy-revisions.json` records all three changed lines with their exact originals. Every panel also retains its original copy and source hash. No image was generated or modified for this edition.

The reader uses the baseline chapter metadata, chosen native dependencies and normalized balloon coordinates. A small new presentation layer strips out gallery controls, review labels and rating forms from the default reading route. The historical reader remains untouched at `docs/pilot-chapters/index.html`.

Integration interface: `docs/pilots-reading-v2/reader.js` exposes `window.ComicReading.renderPanel(panel, assetPrefix = '../../')`. It returns a `<figure>` with native image, editable HTML balloons and SVG tails. The standalone initialization at the bottom expects `window.PILOT_EDITION = {chapters, panels}` and the element ids in index.html. A longform reader can copy the renderer function and CSS or adapt its initialization to consecutive chapters; it should not use the five-story navigation unchanged as consecutive-chapter navigation.

Panel fields: `id`, `source` (repo-relative), `width`, `height`, `alt` (current visible action), `gap_after` (CSS px), and `lettering`. Each lettering record contains `speaker`, `text`, `position` (`overlay`, `above`, `below`), normalized `x/y/w`, normalized `target` (face region, or x outside 0–1 for offscreen), and optional `voice`, `name_cue`, `linked`. Offscreen voices point to the frame edge. Name cues are intentionally retained for NG07's vertically aligned people and ST15's rider above the ram, where a short marginal tail alone was misleading in an actual capture. Production terminology is absent.

Phone captures and actual observations live under `research/nightglass-longform/pilot-lettering/`. Technical fit checks do not establish story quality or acceptance. All 80 baseline art choices remain unchanged; known causal defects are listed in the reader's separate review route.
