# Anchor Return — portable original-world studies

Extract the entire ZIP into a new folder. On Windows, double-click **START_HERE.cmd**, or open **docs/anchor-return/index.html** in your browser. Keep the folders together: original native artwork, reference copies and exact prior choices are loaded locally. No installation, account, server, paid API or network access is required to view the gallery.

Use Gallery for panel details or Read an encounter for one eight-beat sequence. Captions can be toggled. Thirty composition responses and separate sequence comprehension/continuity responses start blank. Export any choices you make from the gallery so you can keep them independently of this package. The preserved earlier choice export is separate. Agent notes and displayed alternatives do not establish owner approval or canon.

Native artwork and every retained attempt are in `production/anchor-return/candidates/`. Exact prompts, calls, copied references, plan, jobs and prior choices are alongside them. Current study notes, QA and code are in `research/anchor-return/`; start with `PIPELINE.md` there for the workflow and `RESULTS.md` for the final observations. The package includes the saved texture skill and its textual guide; historical example galleries are deliberately not included.

For hash verification, additive restoration into a matching Git checkout, or offline reader rebuilding, see `research/anchor-return/asset-bundle/README.md`. Those optional commands need Python 3 using its standard library. Original external tool-return paths in provenance are historical records; all viewing/rebuild dependencies use preserved local copies.
