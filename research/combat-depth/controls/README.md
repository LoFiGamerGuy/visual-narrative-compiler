Editable combat controls

manifest.json selects three scene maps and four projected contact guides. PNGs are locally ignored; SVG sources, rendering receipts and selected source hashes are tracked. All sources are original code-native geometry, rendered with installed librsvg/Cairo through ctypes; no image API or existing raster edits were used.

Map north is up, west left, east right. The south-camera triangle and colored figures are control notation only. Petrol is Riven, teal is Neris, sand is Kellan, plum is Ilyra and gray is enemy. Final art uses bound identity and weapon references, never these schematic faces, colors or arrows as a drawing-treatment reference.

See visual-review.json for actual inspection and remaining limitations. Earlier control versions are preserved. Rendering scripts intentionally reject existing PNG output paths. The first Chrome attempts failed before rendering; task-local logs are retained, and native SVG conversion succeeded.
