# Portable combat exploration

Extract the ZIP and open START_HERE.cmd, or docs/combat-exploration/index.html. The package includes18 selected new design boards, every retained native attempt,9 original drawing references, exact prompts, call records, independent reviews and gallery source. Owner choices stay in the browser until exported separately.

Use bundle_assets.py --help to verify or safely restore missing/identical files. Restoration refuses differing existing files. Rebuild with python research/combat-exploration/reader/build_reader.py --require-complete. Local archives and post-freeze receipts are excluded from the archive itself. The original workspace holds final-v1/combat-exploration-portable.zip under this folder’s local directory.

The built-in generator’s backend model/seed metadata is unknown. Prompts and references are reusable instructions, not a promise of identical regeneration. All earlier experiment deliveries remain in their preserved workspaces.
