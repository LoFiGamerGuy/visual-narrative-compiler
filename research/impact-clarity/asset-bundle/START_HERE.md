# Impact clarity — portable comparison studies

Extract the entire ZIP into a new folder. On Windows, double-click **START_HERE.cmd**, or open **docs/impact-clarity/index.html** in your browser. Keep the folders together: original native artwork, reference copies and exact prior choices are loaded locally. No installation, account, server, paid API or network access is required to view the gallery.

All new responses start blank. Export any choices you make from the gallery so you can keep them independently of this package. The preserved earlier choice export is separate. Agent notes and displayed alternatives do not establish owner approval or canon.

Native artwork and every retained attempt are in `production/impact-clarity/candidates/`. Exact prompts, calls, copied references, plan, jobs and prior choices are alongside them. Current study notes, QA and code are in `research/impact-clarity/`. The package includes the saved texture skill and its textual guide; historical example galleries are deliberately not included.

For hash verification, additive restoration into a matching Git checkout, or offline reader rebuilding, see `research/impact-clarity/asset-bundle/README.md`. Those optional commands need Python 3 using its standard library. Original external tool-return paths in provenance are historical records; all viewing/rebuild dependencies use preserved local copies.
