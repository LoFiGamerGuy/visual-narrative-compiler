# Black Petal cover starter kit

The owner requested preservation of the generator workflow and source material so his wife can explore book covers in this direction. Download [Black-Petal-Cover-Starter.zip](local/Black-Petal-Cover-Starter.zip), extract it, and open `START_HERE.txt`. The ZIP includes both native Black Petal images, both exact original prompts, a cover adaptation template, provenance and a file-hash manifest.

The selected image is [19-retry.png](../../../production/visual-directions/candidates/19-retry.png). It remains the anime gallery reference. Its first return and correction are preserved without alteration. The generation tool is still available in this session; the recipient's separate account has not been checked.

[Official OpenAI documentation](https://learn.chatgpt.com/docs/image-generation) describes built-in generation as GPT Image 2 and documents using an attached image as visual guidance. That current documentation does not recover an exact raster-model version or seed from the original call, whose model metadata remains unknown. Use the preserved image and prompts together; no exact-repeatability claim is made.

The new [cover prompt template](cover-prompt-template.txt) is untested and keeps book-specific fields open. It asks for one vertical composition with room for separate title/author lettering. No book, title, printer format or new cover artwork was invented for the owner.

The ZIP and native copies are local/ignored; text, provenance and archive hashes are tracked. Copy the ZIP separately when sharing the kit. Original artwork remains in the full study bundle as well. The generation study is not reopened by this preservation task.
